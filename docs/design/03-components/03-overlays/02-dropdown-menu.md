# Dropdown menu

Module: `@pbgo/ui/platform/dropdown-menu`

A list of actions behind one button. Rows can carry an icon or a radio; a label heads a group and separators split them. Its panel is glass, like a popover's and a select's: see [Glass, and where the blur lives](03-popover.md#glass-and-where-the-blur-lives).

## Rows

The chosen value belongs to the caller: the component only draws it.

