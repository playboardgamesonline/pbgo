# Checkbox and switch

Module: `@pbgo/ui/platform/checkbox`, `@pbgo/ui/platform/switch`, `@pbgo/ui/platform/label`

A `Checkbox` is one box in a list of options, a `Switch` is a setting that applies at once. Both pair with a `Label`.
