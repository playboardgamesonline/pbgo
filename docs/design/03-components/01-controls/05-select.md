# Select

Module: `@pbgo/ui/platform/select`

A choice among a handful of options, in a popover that opens over the trigger. For two options prefer a `Switch`; for many, a search.

## Default and small

The trigger comes in `default` and `sm`.

```specimen
select-default-and-small
```

## The list

The items stand in from the edge of the list, grouped or not (`SelectGroup` only groups), so a highlight never touches the edge and each corner is the one inside it plus the room between.
