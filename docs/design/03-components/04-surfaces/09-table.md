# Table

Module: `@pbgo/ui/platform/table`

Tabular data with a header row and hairline rows. It scrolls sideways inside its container instead of widening the page. A table in a framed box is a list: the box takes the row's corner (`rounded-2xl`), as the rows of an [item](08-item.md) list do, and never the surface's.
