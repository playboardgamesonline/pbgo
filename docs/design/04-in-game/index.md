# In-game UI

Everything about the UI that `@pbgo/core` draws in a game: first what core provides (screens, HUD, announcements, seat label, game over, skin), then how a game tunes it. The table's pieces (announcements, seat label, end screen) are drawn in the game's own look and shown in these pages in the look of two games side by side, Courtisans and the template: each game owns its universe, the table and the screen around it (the state of the game, the players with their scores, the chat); only the social dock with the menu of the game is the platform's. The rules of the in-game UI (the room for the cookie banner, the compact layout, motion, copy) are in [the guidelines](../01-guidelines/04-in-game-rules.md), the platform's look in [Foundations](../02-foundations/index.md).
