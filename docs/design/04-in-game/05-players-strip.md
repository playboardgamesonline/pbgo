# Players strip

The HUD does not mount it any more: the list of the players at the top right (`TablePlayers`, in the platform's look) says who the game waits for, who is away and what each has so far.

The strip was under the ticker's main line when the game waited for several players at once: one seat label per player, done (✓), waiting or away, and the viewer's own seat marked. Beyond eight seats it collapses to an `n/N ready` button that opens the list.
