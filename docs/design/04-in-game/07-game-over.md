# Game over

The end screen: the winner or winners as the hero (a table that lost together has none: the scoreboard alone), the ranking under it, the score detail of each player (score chips from `renderDetail`), the share thumbnail as a polaroid on the corner, in the game's surface. The table is centered, with a "hide / show" link above the centered PLAY AGAIN button.

`UI_THEME.gameOver` sets the surface (any CSS background), border, radius, ink, accent and polaroid frame (`surface`, `border`, `radius`, `ink`, `accent`, `frame`). Replay plays the entrance of a first opening; the screen is otherwise drawn still.
