# Engine

The guides of the game engines: how the rules of a game become a pure TypeScript engine (`@<slug>/engine`), the contract between an engine and the web app (`@pbgo/engine-kit`), and how a game is built from `template/`.

This section is a shell for now: the guides are written in their own issue. Add a markdown file to this folder, `docs/engine/<name>.md`, and it becomes the page `/docs/engine/<name>`, listed in the menu of the section under the title of its first heading (while `pnpm dev` runs, restart it to give a new file its page: the site lists its pages when it starts). Until then, the guides are in the repository: `packages/engine-kit/README.md` and `template/docs/GAME_GUIDE.md`.
